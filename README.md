# DevPath Careers

Build a complete, modern, responsive website called "DevPortal – Engineering Job Portal".

PROJECT PURPOSE: Create a dedicated job portal for software developers, freshers, experienced engineers, and IT professionals.

DESIGN:

Modern professional SaaS-style UI.

White background with navy blue and purple accents.

Beautiful cards with rounded corners and subtle shadows.

Fully responsive desktop, tablet, and mobile layouts.

Smooth hover effects and animations.

Clean typography and professional icons.

HOMEPAGE:

Navigation bar with logo DevPortal.

Navigation links: Home, Explore Jobs, Applications, About, Contact.

Hero section with heading "Find Your Next Engineering Role".

Job title and location search fields.

Trending technology tags: Java, Spring Boot, React, Python, AWS, Microservices.

Popular hiring companies: Infosys, Razorpay, Oracle, Swiggy, Zomato.

Technical specialization categories.

Recent job openings.

Benefits section.

Footer with contact and navigation links.

JOB CATEGORIES:

Java & Backend Development.

Frontend & Full Stack.

Cloud & DevOps.

Data Science & AI.

Mobile Development.

QA & Testing.

JOB LISTINGS: Create sample jobs with:

Job title.

Company name.

Location.

Experience required.

Salary range in INR.

Required skills.

Employment type.

Apply Now button.

FUNCTIONALITY:

Job search by title and technology.

Search jobs by location.

Filter jobs by category.

Filter remote, hybrid, and onsite jobs.

Job details page.

Apply Now button.

Application tracking dashboard.

User registration and login interface.

Employer job posting interface.

Resume upload interface.

APPLICATION TRACKER: Display application statuses:

Applied.

Under Review.

Interview Scheduled.

Selected.

Rejected.

IMPORTANT: Make all navigation links and buttons functional. Use sample data initially. Store application data persistently if a backend is configured. Do not pretend that sample jobs are verified real vacancies. Include form validation and user-friendly error messages.

TECHNOLOGY: Use React, TypeScript, Tailwind CSS, and reusable components.

Make the website visually impressive and suitable for a final-year college engineering project demonstration.
